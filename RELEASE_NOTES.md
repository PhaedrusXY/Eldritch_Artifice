# Eldritch Artifice 0.11.13

Adds tier 5 Eldrin Altar recipes for the Hood, Vestment, Wraps, and Steps of the Open Eye. Each requires 2750 Ender power; the hood also requires 1500 Arcane, the wraps 1500 Earth, and the steps 1500 Wind. The chest piece uses Ender alone, matching the other faction armor recipes' power budgets. Each recipe has nine item offerings and requires Eldritch faction and tier 5.

The codex's Vestments of the Open Eye entry now links all four altar recipes. This is a resource-only update to 0.11.12: compiled classes are reused without modification. Checked the JSON recipe format against Mana and Artifice 3.1.11 armor recipes and the referenced M&A and Dimensional Doors item model identifiers against the dependency jars. No live server crafting test was run.
